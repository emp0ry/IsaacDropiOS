THE DETAILS

Less friction
More of the game.

Focused control and HUD improvements for the supported native iOS game.

01

Drop, without the detour.

Tap the invisible bottom-left zone to cycle D Infinity without using it or spending charge. Hold it for native Drop of eligible pocket items and trinkets.

Hardware Ctrl cycles once per press and still allows hold-to-drop.

02

Keep the rhythm.

Hold R or the top-center touch zone for a fresh run. Esc toggles pause, Enter confirms like Space, and F toggles native macOS fullscreen in PlayCover.

The gameplay cursor hides after three idle seconds in PlayCover.

03

Read the small details.

Sharper Extra HUD Mini uses original 32×32 art at display resolution. Planetarium Chance follows the native per-floor percentage and Found HUD positioning.

HUD work is confirmed in PlayCover; physical-device coverage remains separate.

GETTING STARTED

One mod
One loading method.

Install the format for your host and keep other independent Isaac mods intact.

Full installation guide ↗
  1. Install or update the DEB.

    Use a compatible package manager. Its retained package identity upgrades the former Drop package.

  2. Restart Isaac.

    Fully close and reopen the game before checking the controls.

  1. Replace the old framework.

    Use the new app-specific IsaacFixes framework instead of the old Drop framework.

  2. Use one copy.

    Do not enable both. Fully restart Isaac after selecting the app-specific tweak folder.

  1. Back up the application.

    Preserve the app and its entitlements before replacing embedded libraries.

  2. Use the matching platform.

    The iOS and PlayCover libraries are different. Embed the correct binary as IsaacFixes.dylib or use the existing documented Drop load path.

  3. Sign and restart.

    Sign the complete app with its existing entitlements. Keep EID, Steam Sync and Debug Console intact.

Upgrading from Drop: replace the old library or framework. You may keep the IsaacDrop.dylib load path with the replacement build, but never load both. Remove the separate experimental IsaacEnterSpace.dylib command if installed.

A LITTLE MORE CONTEXT

Good to know.

Does restart work like R Key?+

No. It starts a fresh run, discards acquired items and follows native character, difficulty, seed and Eden-token restrictions.

When do touch holds stop?+

Sliding out, pausing, backgrounding or losing the game host cancels held input. Text fields, Console input, dialogs and modified shortcuts are left alone.

Does this distribute game artwork?+

No. HUD icons and fonts are read from the installed game. No IPA, game executable, extracted art or save is included.
