Small fixes.
Native controls.

The controls Isaac’s iOS version leaves out, together in one mod. Drop and switch D Infinity, hold R to restart, and press Esc to pause. In PlayCover, Enter confirms like Space and F toggles fullscreen. No extra buttons on your screen.

01 / TAP

Switch D Infinity

02 / HOLD

Drop what you’re carrying

Keep your finger in the zone for the game’s normal drop threshold, about three seconds. Eligible trinkets and pocket items follow Isaac’s own drop rules.

CardsRunesPillsTrinkets

No equipped trinket is needed to drop a pocket item.

Hold R, or hold the top-center zone.

After one second, start a fresh run with the same character and difficulty. Keep holding to restart every second; release to stop. Native loading can lengthen the interval. Pausing, opening text entry or losing focus cancels the hold. This is a full restart, not the R Key item.

Esc to pause. Esc again to resume.

Works with hardware keyboards and PlayCover. One toggle per press, even when held. Text entry, presented dialogs and modified shortcuts are left alone. Pausing cancels any held-R loop.

PLAYCOVER / ENTER

Enter does what Space does

Confirm the selected pause-menu option: Continue resumes the run; Options opens Options. Ordinary and keypad Enter use the game’s own Space input. Debug Console text entry stays normal.

PLAYCOVER / F

Fullscreen. And back.

Press F to enter native macOS fullscreen; release and press again to return to windowed mode. Holding F toggles once, and presses during the native animation do not queue extra transitions. Text fields and modified shortcuts are left alone.

Focused fixes, native rules.

D Infinity cycling is supported. Other short-press Ctrl behaviors are not yet fully supported by the iOS touch path. Sliding out, pausing or backgrounding cancels the held input.

Getting started

Install once. Restart Isaac.

No description database, Steam account or configuration panel is needed. Upgrading from Drop or the experimental Enter mod? Replace those copies instead of loading duplicates.

A

Rootless jailbreak

  1. Download IsaacFixes-rootless.deb.
  2. Install it with your package manager. ElleKit is the loader.
  3. Fully restart Isaac, enter a run, and use the bottom-left zone.
B

LiveContainer

  1. Download the LiveContainer.framework.zip archive.
  2. Import it into Isaac’s app-specific tweaks using LiveContainer’s tweak controls.
  3. Fully restart the guest app. Do not load a second copy through another method.
C

Direct embedding

  1. Place IsaacFixes.dylib in the app’s Frameworks directory.
  2. Add a load command for @executable_path/Frameworks/IsaacFixes.dylib.
  3. Sign the dylib and complete app bundle, then install it using your existing signing setup.

PlayCover uses the Mac Catalyst build, not the iPhone dylib. Preserve the existing app entitlements and other mods when re-signing. Remove the standalone IsaacEnterSpace load command and replace the old Drop library; load only one copy of Isaac Fixes. No Isaac IPA, extracted game assets or purchase bypass is included.

Good to know

One mod. Clear limits.

I cannot see the buttons. Is that normal?

Yes. During an unpaused run, the bottom-left 72 × 64 screen points are Drop and the top-center 72 × 64 points are Restart. Both zones are invisible and disabled in menus and while paused.

Does it work without a jailbreak?

The dylib has no jailbreak dependencies. LiveContainer and direct embedding are supported loading formats; a directly embedded dylib must be code-signed with the app. This is not an App Store app and does not change Apple’s signing requirements.

Will it delete my card or use the die?

Holding supplies the game’s native Drop input; the game handles eligible drops. D Infinity tapping changes its selected mode and refreshes the native HUD, without activating the item. The mod does not edit save files directly.

Does it replace every Ctrl action?

No. This release supports D Infinity cycling and native hold-to-drop. Other short-press Ctrl behaviors still need their own iOS compatibility work.

Something does not work on my device.

First fully restart Isaac and check that only one copy is loaded. Include your game version, loading method and exact steps in a GitHub issue. The diagnostic log is at Library/Application Support/IsaacFixes/fixes.log inside Isaac’s own container.
